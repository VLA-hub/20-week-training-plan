20-Week Half-Marathon Training App prototype

Files:
- index.html: mobile-friendly app
- manifest.json: installable web app metadata
- sw.js: basic offline caching

Features: weekly running schedule, strength workouts, week selector, checkmarks, progress tracker, optional race date, local save, export progress.

To install on iPhone: host these files on an HTTPS website. Open the hosted URL in Safari > Share > Add to Home Screen. This is not an App Store app. Checkmarks are stored locally on that device/browser and do not automatically sync.
